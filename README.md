# \# CS-330: Computational Graphics and Visualization



\## How do I approach designing software?



When I start designing software, I like to break the project down into smaller pieces instead of trying to complete everything at once. This course helped me understand how important planning is, especially when working with 3D graphics. While creating my Alchemy Table scene, I had to figure out how different shapes could work together to create objects that looked the way I wanted. I also learned how to create some of my own shapes when the basic shapes were not enough, especially when working on the curves of the potion bottle and the crystals. Throughout the project, I made adjustments to the positioning, scaling, textures, and lighting until everything came together. I plan to continue using this approach in future projects because it makes larger tasks easier to manage and gives me the opportunity to make improvements along the way.





\## How do I approach developing programs?



When developing programs, I have learned that it is better to work on one feature at a time and test it before moving on to something else. Throughout this course, I used this approach while building my Alchemy Table scene. I started with basic 3D shapes and gradually added more complicated features, including textures, camera movement, lighting, and transparency. There were several times when something did not work the way I expected, especially when trying to make the potion bottle transparent while keeping the liquid visible inside. Instead of changing everything at once, I would make small adjustments, run the program, and see how those changes affected the scene. Working through the different milestones helped me become more comfortable troubleshooting problems and understanding how different parts of the code work together. This course also showed me how important testing and making improvements are throughout the development process, rather than waiting until the entire project is finished.





\## How can computer science help me reach my goals?



Computer science is helping me build the skills I need to pursue a career in software development, especially in application and game development. Before taking this course, I did not realize how much work went into creating and displaying 3D objects in a program. Working with OpenGL helped me better understand how graphics are rendered and how things like lighting, textures, camera movement, and object positioning affect what the user sees. Creating my Alchemy Table was one of the more enjoyable projects I have worked on because I was able to take an idea and gradually turn it into something I could actually interact with. I also gained more experience working with C++ and troubleshooting code, which are skills I can use in future classes and professional projects. Even if I do not work directly with 3D graphics in my career, the problem-solving and development skills I gained from this course will still be useful.
